高效推理：vLLM

一部署vLLM:分步指南

简明介绍了 vLLM 在本地部署开源大语言模型的流程及关键特性：

  • 核心优势：vLLM 提供高吞吐、低延迟的推理性能，支持 HuggingFace 格式模型
  • 部署流程：支持使用 python -m vllm.entrypoints.openai.api_server 启动 OpenAI 风格 API 服务
  • API调用：与 OpenAI 接口一致，支持 Chat、Completion 等常见参数（如 temperature, top_p, stream 等）
  • 安装方式：一行命令 pip install vllm 即可开始，GPU支持建议 Compute Capability ≥ 7.0
  • 支持模型：LLaMA、ChatGLM、Qwen、Baichuan 等主流模型均已验证可用

适合希望快速落地本地 LLM 服务、并进行高效推理部署的算法工程师与大模型应用开发者。

VLLM分布式推理进阶1：数据并行 vs 张量并行

深入探讨了 vLLM 在多卡分布式推理场景下的两种并行策略及其性能表现：

  • 实验设置：4张GPU、1700条样本、max_new_tokens=2048，模型单卡可容纳
  • 张量并行：通过 tensor_parallel_size=4 启用张量切分并在4卡上协同推理，耗时344.97s
  • 数据并行：借助 Ray 将样本切分为4份并发运行，每卡1份，共用4张GPU，耗时182.11s
  • 对比结论：在模型单卡可放下的前提下，数据并行推理效率是张量并行的1.89倍
  • 技术机制：张量并行需大量GPU间通信，Ray调度的数据并行任务间无依赖、可独立运行

适合希望提升大模型推理吞吐、理解不同并行策略在vLLM下实践效果的工程师与优化人员。

RAG的2024—随需而变，从狂热到理性

总结2024年RAG技术演进与市场变化，分析企业应用趋势及从业者生态：

  • 技术架构优化：Advanced RAG成为主流，索引组织（如元数据增强、指代消解）和混合检索（Hybrid+RRF+ReRank）显著提升准确率，知识提取工具应对多样化文件需求。
  • 市场需求转变：上半年追求“大而全”的AI解决方案遇冷，下半年转向“小而难”的垂直场景（如高精度问答），RAG因知识管理灵活、幻觉控制优势超越微调。
  • 市场阶段特征：AI技术从“过高期望”进入“理性沉淀期”，企业更关注实际价值（降本增效），应用层竞争或成2025年核心。
  • 从业者生态变化：自媒体热度下降，部分企业AI团队解散，但深耕垂直领域（法律、医疗等）的团队开始创造客户价值。
  • 未来趋势预测：知识管理与协作工具需求激增，非结构化数据激活催生新挑战，RAG将与企业流程深度结合。
    适用人群：AI技术从业者、企业技术决策者、关注RAG落地的开发者及垂直领域数字化转型探索者。

总结与思考

通过整合以上资源，我们可以看到 RAG 技术体系的几个关键发展方向：

  1. 向量索引技术在不断演进，Faiss 等工具提供了高效的相似度检索基础
  2. 推理优化对于 RAG 系统的实时性至关重要，vLLM 等技术显著提升了推理效率
  3. 文本分块仍是影响 RAG 质量的关键因素，行业正从简单的固定长度分块向语义化、层次化方向发展
  4. 系统集成与优化需要综合考虑多个环节，包括检索策略、排序重排、结果合成等

对于希望构建高质量 RAG 应用的开发者，建议结合自身应用场景，选择适合的技术组合，并持续关注该领域的最新进展。
