Day 1：理解LangChain架构与核心模块

一、LangChain 的定位与核心设计理念

定位

LangChain 是一个用于开发由语言模型驱动的应用程序的框架。它提供了一套工具和组件,用于构建复杂的、基于语言模型的应用 LangChain 是一个专为构建基于大语言模型（LLM）的应用而设计的开源框架。它将复杂的 AI 应用开发任务拆解为模块化组件，使得开发者能够快速构建、调试和扩展多轮对话、问答系统、文档分析、自动化工作流等应用。

核心设计理念

  1. 模块化架构：将整体任务拆分为独立、可复用的组件，如提示模板、模型调用、记忆管理、文档加载、向量检索、链（流程编排）和智能代理。
  2. 标准化接口：封装了不同大模型（如 OpenAI、Anthropic、Hugging Face、本地模型）的调用差异，统一调用方式，降低切换模型的成本。
  3. 上下文感知：通过记忆组件与检索增强生成（RAG）技术，帮助模型在多轮对话和复杂任务中保持上下文一致性和准确性。
  4. 灵活扩展：各组件之间耦合度低，支持自定义扩展，例如自定义工具、提示模板和数据连接器，适应垂直领域需求。

二、LangChain 的主要模块与功能

Model I/O：

标准化各大模型的输入输出，包括输入模板，模型本身和格式化输出

1.1 提示模板（Prompts）

  • 作用：构造模型输入，动态生成问题指令，支持变量插值。
  • 关键组件：
    • System Prompt：设定角色和行为，如“你是一个知识渊博的助手”。
    • Human Prompt：用户输入部分，决定最终生成内容的上下文。
  • 应用：在对话、问答、内容生成中均发挥核心作用。

    1.2 语言模型（Language Models）

  • 作用：统一大模型调用接口，支持 GPT-4、Llama、Claude 等多种模型。
  • 特点：支持流式输出、同步或异步调用，便于适应不同场景需求。

    1.2 parse

    链（Chains）

  • 作用：将多个组件串联起来，形成从输入到输出的完整流程。
  • 类型：
    • LLMChain：简单的单一调用。
    • SequentialChain：顺序执行多步骤任务。
    • RouterChain：根据输入动态选择不同子链。
  • 应用：在问答、生成、数据处理等多步骤任务中组合各模块。

    智能代理（Agents）

  • 作用：使模型具备决策能力，能够自主调用外部工具（如搜索、API 调用）来解决问题。
  • 特点：支持 ReAct、Self-ask 等代理策略，实现任务分解与执行。

    记忆（Memory）

  • 作用：管理对话上下文，保持多轮对话的连续性。
  • 类型：
    • 短期记忆：存储当前对话历史。
    • 长期记忆：持久化存储用户交互数据，支持跨会话引用。

      retrievers

      该模块是支持对各种数据存储的检索，该模块基本集成了市面上常用的向量检索的工具，比如weaviate、pinecone,chroma等，及文本检索如elastic_search_bm25等。

      数据连接（Indexes 与 Document Loaders）

  • 作用：加载、处理和存储各种文档数据，并将文本嵌入向量空间，支持语义搜索。
  • 组件：
    • Document Loaders：支持 PDF、文本、CSV、JSON、Docx 等格式。
    • Text Splitters：如 RecursiveCharacterTextSplitter，负责将长文档拆分为合适长度的片段。
    • vectorstores 向量存储：集成 FAISS、Chroma 等，用于检索增强生成（RAG）。

三、典型应用场景

  • 智能问答系统：通过知识库检索与多轮对话记忆，为用户提供精准回答。
  • 文档分析助手：整合文档加载、文本分割、语义搜索，辅助信息提取和分析。
  • 代码生成与辅助开发：利用提示模板和模型调用，生成代码、自动化错误检查。
  • 自动化数据分析报告：链式调用模型生成报告内容，并通过外部工具制作图表。
  • 个性化聊天机器人：结合 Agents 和记忆模块，实现自主决策和工具调用。
