langchain笔记Day1 总体架构与核心模块

📘 Day 1：理解 LangChain 架构与核心模块

一、LangChain 的定位与核心设计理念

1.1 定位

LangChain 是一个用于开发由语言模型驱动的应用程序的框架，专为构建基于大语言模型（LLM）的应用而设计。
它将复杂的 AI 应用开发任务拆解为模块化组件，使开发者能够快速构建、调试和扩展如下应用：

  • 多轮对话系统
  • 问答系统
  • 文档分析
  • 自动化工作流

1.2 核心设计理念

  1. 模块化架构：任务拆分为提示模板、模型调用、记忆管理、文档加载、向量检索、链、智能代理等可复用组件。
  2. 标准化接口：统一调用 OpenAI、Anthropic、Hugging Face、本地模型等，降低模型切换成本。
  3. 上下文感知：结合记忆组件与 RAG 技术，保持多轮对话和复杂任务的上下文一致性。
  4. 灵活扩展：支持自定义组件（工具、模板、连接器），适配垂直领域应用需求。

二、LangChain 的主要模块与功能

2.1 Model I/O

标准化各大模型的输入输出，包括提示模板、模型调用及输出解析。

🧩 2.1.1 提示模板（Prompts）

  • 作用：构造模型输入，支持动态变量插值。
  • 关键组件：
    • System Prompt：设定角色与行为，如“你是一个知识渊博的助手”。
    • Human Prompt：用户输入部分，提供上下文。
  • 应用：用于对话生成、问答系统、内容创作等。

🧠 2.1.2 语言模型（Language Models）

  • 作用：统一大模型调用接口，兼容 GPT-4、LLaMA、Claude 等。
  • 特点：
    • 支持同步/异步调用
    • 支持流式输出
    • 易于适配不同业务场景

2.2 解析器（Parse）

将 LLM 输出解析为结构化数据，便于后续程序处理。

  • 关键组件：
    • Output Parsers：如 StructuredOutputParser、PydanticOutputParser，将文本转为 JSON、字典等。
    • RegexParser：基于正则提取关键信息。
    • RetryParser/Guardrails：处理输出格式错误，进行重试或修正。
  • 应用场景：
    • 信息提取（如时间、地点、人物）
    • 意图识别与槽位提取
    • 接口集成时对输出格式的控制（如数据库、API）

2.3 链（Chains）

将多个组件连接，构建从输入到输出的完整处理流程。

  • 常见类型：
    • LLMChain：简单的单步调用链
    • SequentialChain：多个步骤按顺序执行
    • RouterChain：根据输入动态选择子链执行
  • 应用：
    • 问答系统
    • 内容生成
    • 多步骤流程自动化

2.4 智能代理（Agents）

构建具备工具调用能力与任务分解能力的模型。

  • 核心能力：
    • 决策与行动规划（如 ReAct、Self-ask 策略）
    • 自主调用外部工具（搜索引擎、API、数据库等）
  • 适用场景：
    • 多工具任务调度
    • 自动化问答或信息收集
    • 自我反思与纠错任务

2.5 记忆（Memory）

实现对话的上下文管理，保持多轮对话的连续性。

  • 类型：
    • 短期记忆：当前对话轮次的记录
    • 长期记忆：跨会话保存用户信息或重要内容
  • 作用：
    • 提高上下文一致性
    • 支持个性化与持续对话体验

2.6 检索器（Retrievers）

向量与全文检索的接口封装模块。

  • 支持类型：
    • 向量检索：如 FAISS、Chroma、Weaviate、Pinecone
    • 文本检索：如 ElasticSearch、BM25
  • 功能：
    • 快速定位相关文档片段
    • RAG 系统核心组件

2.7 数据连接（Indexes 与 Document Loaders）

用于加载、处理、存储文档数据，并生成可检索向量。

  • 核心组件：
    • Document Loaders：支持 PDF、TXT、CSV、JSON、Docx 等格式
    • Text Splitters：如 RecursiveCharacterTextSplitter，将长文本合理拆分
    • Vectorstores：向量数据库集成（如 FAISS、Chroma）
  • 应用场景：
    • 文档搜索
    • RAG 检索增强生成
    • 数据驱动型问答系统

三、典型应用场景

💬 智能问答系统

  • 融合知识库检索、记忆模块与多轮对话，提升准确性与交互体验。

📄 文档分析助手

  • 加载企业文档、进行结构化提取与语义搜索，辅助数据洞察与分析。

💻 代码生成与辅助开发

  • 通过链与提示模板组合，自动生成代码片段、修复逻辑、生成注释。

📊 自动化数据分析报告

  • 自动读取结构化数据并调用模型撰写分析报告，结合工具生成图表展示。

🧠 个性化聊天机器人

  • 结合 Agents 和 Memory，构建具备工具调用能力和长期记忆的 AI 助手。
